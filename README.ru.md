# FrameForge Recorder

[English](README.md) · [Русский](README.ru.md)

Программа для Windows: запись экрана, отдельного окна или выбранной области в MP4.

Изготовитель: **Victor Kirsanov**.
Лицензия: [MIT](LICENSE). Можно использовать, менять и распространять код с сохранением уведомления об авторстве.

## Установка

[Скачать актуальный инсталлятор](https://github.com/viktorkirs/FrameForge/releases/download/latest/FrameForge-Setup-x64.exe).
Эта постоянная ссылка обновляется после успешной сборки и проверок каждого push в `main`.
Версия программы и исходный коммит указаны в описании сборки.
Отдельные версионные выпуски доступны в [релизах](https://github.com/viktorkirs/FrameForge/releases).
Установщик включает .NET, создаёт ярлык в меню «Пуск» и предлагает ярлык на рабочем столе.
Установка выполняется для текущего пользователя. Удаление доступно через настройки Windows;
видеозаписи и настройки сохраняются.

[Code signing policy — политика подписи](CODE_SIGNING_POLICY.md) · [Конфиденциальность](PRIVACY.md).
Готовится подключение бесплатной подписи SignPath Foundation. Текущие опубликованные установщики пока не подписаны.

Требуется Windows 10 версии 2004 или новее либо Windows 11, совместимая с x64.

## Возможности

- Запись монитора, окна или области; аппаратное и программное кодирование H.264.
- Системный звук и микрофон, выбор устройств и круглые индикаторы уровня звука.
- Пауза, скриншоты и настраиваемые горячие клавиши.
- Видеоредактор с предпросмотром, звуковой волной, разрезанием, независимым сдвигом и обрезкой связанных видео и звука.
- Несколько видеоисточников, дополнительные видео- и аудиодорожки, запись озвучки с выбранного микрофона при просмотре.
- Обрезка кадра мышью с ручками и сеткой, сдвиг, размер, поворот на 90°, плавное появление и исчезновение.
- Готовые горизонтальные, вертикальные и квадратные форматы для предпросмотра и экспорта MP4.
- Сохранение незавершённого монтажа в собственный формат проекта `.ffproj`.
- Перемещение выбранной области и редактирование её размера до записи.
- Выбор окон с миниатюрами и поиском.
- Плавный курсор с инерцией, дугой или спиральной траекторией.
- Временный жёлтый маркер: включите его в **Настройки → Курсор**, удерживайте
  **Alt + левую кнопку мыши** для рисования; отпустите Alt для очистки.
- Интерфейс на русском, английском и немецком языках.

В редакторе перетаскивайте кадр для сдвига, а ручки рамки — для изменения размера.
На главном экране **Запись** и **Редактор** доступны как равноправные разделы. Переключение
к записи приостанавливает предпросмотр, а возвращение в редактор сохраняет незавершённый монтаж.
Клипы не сдвигают соседей при обрезке, перемещении или удалении. Свободные промежутки
остаются чёрными и без звука в предпросмотре и готовом MP4.

Колесо прокручивает список дорожек, **Ctrl+колесо** — время по горизонтали. Ползунок
**Высота дорожек** делает их компактнее. Разделители меняют размеры превью, дорожек и правой
панели инструментов. Стрелки прокручивают время, а **Уместить** показывает весь монтаж.

Тяните по шкале времени или с Shift, чтобы выделить одну зону всех дорожек.
**Вырезать зону** (`Ctrl+X`) копирует и удаляет её, сохраняя позиции остальных клипов;
Delete удаляет без копирования. `Ctrl+C` / `Ctrl+V` копируют и вставляют клипы или зоны.
**Копировать дорожку / Вставить дорожку** (`Ctrl+Shift+C` / `Ctrl+Shift+V`) создают независимую
копию с прежними позициями. Если при вставке место занято, используется новая дорожка.
**Обрезать кадр** показывает исходник целиком: тяните за ручки или выделяйте новую область,
затем нажмите **Готово**. Shift позволяет сдвинуть область обрезки. Точные числа доступны
в раскрываемом блоке **Точные настройки**. Ползунки задают длительность появления и исчезновения.

**Добавить видео** дописывает файл на главную дорожку. Для наложения сначала создайте
**Видеодорожку**, затем добавьте файл: он начнётся с текущей позиции. Дополнительные дорожки
сохраняют свои временные позиции; блоки можно двигать и обрезать мышью. Кнопка звука у названия
выключает дорожку. **Записать озвучку** запускает просмотр и микрофон; остановка добавляет
запись отдельной дорожкой. WAV хранится в подпапке `Voiceovers` каталога записей.

**Добавить изображение** создаёт отдельный слой; прозрачность PNG сохраняется в превью и MP4.
**Добавить текст** создаёт редактируемую надпись. Справа можно выбрать шрифт, размер, цвет,
прозрачность, жирное начертание, курсив, подчёркивание и выравнивание, ввести несколько строк.
Двигайте слой и меняйте размер ручками в превью. Длительность меняется краями блока на таймлайне
или в поле **Длительность слоя**. Можно начать проект с изображений и текста без исходного видео.

Перетаскивайте изображения, видео и звук из Проводника прямо в редактор. Сброс на таймлайн
задаёт время начала под мышью; сброс на превью использует текущую позицию. Каждый файл получает
отдельную дорожку. Один файл `.ffproj` можно перетащить для открытия проекта.

**Сохранить проект** (`Ctrl+S`) сохраняет монтаж в `.ffproj`; `Ctrl+Shift+S` — копию,
`Ctrl+O` — открытие проекта. Текст и оформление сохраняются внутри проекта. Видео, WAV и изображения
остаются отдельными файлами: переносите их вместе с проектом. Проекты прежних версий открываются автоматически.
Относительные пути позволяют переносить всю папку, а пропавший исходник можно указать заново.
Рамка захвата и её панель скрываются на всё время работы видеоредактора.

При первом запуске программа предложит выбрать язык. Позже его можно изменить в **Настройки → Общие → Язык**.

При запуске программа проверяет наличие нового установщика на GitHub и предлагает его скачать.
Ручная проверка находится в **О программе → Проверить обновления**; автоматическую можно отключить
в **Настройки → Общие**. Установщик скачивается через браузер, установку запускаете вы.

После остановки записи нажмите **Редактировать видео**. Редактор также доступен по значку карандаша
в верхней панели: можно открыть ранее записанный MP4. Щёлкайте по шкале для перемотки,
используйте **Разрезать** (`Ctrl+B`), перетаскивайте блоки для сдвига или их края для обрезки.
`Delete` удаляет выбранный блок, `Ctrl+Z` / `Ctrl+Y` отменяют и повторяют изменения, пробел включает просмотр.
Поля начала и конца позволяют задать точное время в исходной записи. **Экспорт MP4** сохраняет новый файл,
оставляя оригинал целым; видео и звук редактируются вместе, без промежутков между блоками.

## Сборка

На Windows с .NET 10 SDK:

```powershell
dotnet build FrameForge.slnx -c Release
dotnet run --project src/FrameForge.UI -c Release
```

Установщик (PowerShell 7+):

```powershell
pwsh -File installer/Build-Installer.ps1
```

Готовый файл и контрольная сумма появятся в `dist/`.
Инструкции по сборщику находятся в [installer/README.txt](installer/README.txt).

## Проверки

```powershell
dotnet run --project tests/FrameForge.RegressionTests -c Release -- artifacts/verification --capture --audio
```

Проверки захвата требуют интерактивного рабочего стола и аппаратного H.264-кодировщика.
Аудиопроверки кратко воспроизводят тестовый тон и проверяют захват системного звука и микрофона.
Результаты сохраняются локально в `artifacts/`, тестовые настройки изолированы от пользовательских.

Проверки монтажа, предпросмотра и экспорта на синтетическом видео со звуком:
`dotnet run --project tests/FrameForge.RegressionTests -c Release -- artifacts/verification/editor --editor`.

Проверка установщика после сборки:

```powershell
pwsh -File installer/Test-Installer.ps1
```

Она устанавливает программу во временную папку, проверяет запуск и запись, повторную
установку и удаление. Если FrameForge уже установлен, проверка прекращается,
чтобы сохранить существующую установку.

Используется NAudio; текст его лицензии находится в
[src/FrameForge.UI/NAudio-LICENSE.txt](src/FrameForge.UI/NAudio-LICENSE.txt).
