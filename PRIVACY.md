# Privacy policy

FrameForge Recorder is a local Windows screen recorder created by Victor Kirsanov.

## Recording and storage

The program captures the monitor, application window or screen region chosen by the user.
System audio, microphone audio, cursor effects and temporary annotations are controlled by the user.
Video, audio and screenshots are written to the selected output location. Settings and local
diagnostics are stored in the application's user-data folder (or the portable data folder).

FrameForge does not upload this content, collect analytics, report crashes to a server, or perform
automatic network update checks. It contains no advertising or account sign-in. Bundled capture,
audio and encoding components process recording data locally.

Files saved into a network share or a cloud-synchronized folder are subject to the user's chosen
storage provider and sync software. Removing the application preserves recordings and settings;
users can delete those files themselves.

## Website, downloads and code signing

The source repository, issue tracker, downloads and CI are hosted on GitHub. Visiting these pages
or posting an issue is subject to [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
Please review any diagnostic details before sharing them in a public issue.

If approved for SignPath Foundation signing, CI will send application build artifacts and build
provenance to SignPath. This process does not include application users' recordings or local logs.
The maintainer's signing account and application are subject to
[SignPath's privacy policy](https://signpath.io/privacy-policy).

## Contact

Questions about FrameForge can be raised in the public
[issue tracker](https://github.com/viktorkirs/FrameForge/issues). Do not post private recordings
or sensitive information there.
